# A股量化信号引擎

一个本地运行的 A 股选股信号系统：全市场取数 → 构造量价因子 → LightGBM 滚动训练 →
组合构建与 T+1 回测 → 每日买卖信号与可视化看板。

**这是研究工具，不是投资建议系统，不承诺任何收益。** 回测绩效与实盘之间的差距，
见下方「实测结论」与「能力边界」。

## 快速开始

```bash
# 1. 下载新版日线行情（首次需建立独立缓存，之后增量更新）
python scripts/01_fetch.py

# 2. 构建因子、训练模型、回测（首次约 12 分钟，有缓存后约 1 分钟）
python scripts/02_build.py

# 3. 启动看板
python scripts/serve.py --open          # http://127.0.0.1:8710
```

环境要求：Python 3.12+，依赖版本锁定在 `requirements.txt`（`python -m pip install -r requirements.txt`）。在线更新行情用 `baostock` 提供证券主表、交易日历及停牌状态；`akshare` 只用于外部数据（`scripts/09_fetch_ext.py`）。
无需 API key，无需付费数据源。

## 实测结论（请先读这一段）

**次日开盘回测的时点已修正。** 用原有预测、相同股票池和交易成本重放，43 因子默认组合（带闸门）的扣费年化为 **9.78%**、最大回撤幅度为 **24.37%**；在相同配置下加入 6 个外部因子，分别为 **6.40%** 和 **26.03%**。年化包含训练预热期间的空仓日，数据截至 2026-11-20。这些是历史回测，不是实盘收益。

以下表格、分年结果和后续调参记录保留作历史对照，采用修正前的开盘时点；未经重新回放，不应当作当前引擎的绩效。已生成的看板数据不会随代码修改而自动刷新。

|---|---|---|---|
| 累计收益 | **-0.7%** | **+110.4%** | +33.2% |
| 年化收益 | -0.1% | **+10.0%** | +3.7% |
| 最大回撤 | **-51.0%** | **-24.0%** | — |
| 夏普比率 | -0.00 | **0.59** | — |
| 超额年化 | -5.2% | **+3.4%** | — |
| 信息比率 | -0.23 | **0.16** | — |
| 年化换手（单边） | 1125% | 673% | — |
| IC 均值 | 0.091 | 0.091 | — |

分年度超额（新默认配置，6 个真实交易年）：

| 年份 | 2021 | 2022 | 2023 | 2024 | 2025 | 2026 |
|---|---|---|---|---|---|---|
| 超额 | +16.2% | +27.7% | +21.1% | +12.8% | +11.3% | +13.5% |

**6 年全部为正，最差年 +11.3%** —— 这一点比总收益更重要，说明结果不依赖某一年。

三个关键事实：

1. **模型确实有预测能力。** IC 均值 0.091、ICIR 0.56、IC 胜率 77%，分层收益单调
   （第 1 层 -0.30%、第 3 层 +0.61%），多空价差 71 期全部为正。同期等权因子合成的
   基线 IC 是 **-0.087**，说明 LightGBM 相对朴素方法有实质提升。

2. **但把打分直接等权做多是亏钱的。** 模型学到的核心是「短期反转」——买入跌幅最深的
   一批小微盘股。这类股票在 2024 年初的微盘股流动性危机里同步崩盘，单次事件
   （2023-02 至 2024-04，-51%）就抹掉了全部累计 alpha。

3. **收益主要来自「什么时候空仓」，而不是「买哪只」。** 加入沪深300 60 日均线闸门后
   绩效翻转。这既是本系统最有效的一层，也是最脆弱的一层——见下方局限第 ① 条。

## 优化实验记录（试过什么、什么有效、什么无效）

所有实验都是固定模型打分、只改组合构建层，因此可复现且与重训无关。
完整数据见 `output/optimize_experiment.csv`、`output/selection_experiment.csv`。

### 有效的改动

| 改动 | 效果 | 为什么 |
|---|---|---|
| **逆波动加权** | 回撤 -24.0%→-23.0%，夏普 0.55→0.57 | 低波动股给更高权重，组合方差下降而 alpha 不损失 |
| **闸门加入迟滞** | 年化 8.7%→9.5%，历史翻转 114 次→42 次 | 纯均线穿越在震荡市反复进出，成本与踏空双杀 |
| **持仓 20 只→15 只** | 年化 8.7%→10.0%，最差年超额 +4.9%→+11.3% | alpha 集中在前 15 名内，过度分散会稀释信号 |

`top_n` 的平滑性已单独验证（8/10/12/15/20/25/30 只对应年化 11.6/13.0/12.3/10.0/9.5/9.8/9.2%），
呈平滑单峰而非尖刺，说明是真实效应。最终取 15 是在收益与集中度风险之间的折中，
**不是收益最优点**（10 只回测更好但个股特质风险明显更高）。

### 无效甚至有害的改动

| 改动 | 结果 | 为什么失败 |
|---|---|---|
| **回撤刹车** | 年化 8.4%→3.0%（10% 刹车） | 本策略 alpha 正是「暴跌后买入」，刹车恰好在最有优势时离场 |
| **市场宽度闸门** | 年化 8.4%→2.0%（宽度 50%） | 宽度指标太慢，反弹初期迟迟不进场，错过主要涨幅 |
| **加流动性下限** | 年化 -0.1%→-6.2% | alpha 的来源就在低流动性小盘股，过滤流动性等于过滤 alpha |
| **规模中性化** | 年化 -9.1% | alpha 本身就是小市值效应，中性化把它去掉了 |
| **标签周期对齐到 20 日** | 年化 8.7%→2.7%，回撤 -24%→-47% | IC 相同（0.091）但组合更差：10 日标签捕捉的短期反转更强，20 日标签噪声更大 |

最后一条尤其反直觉：**标签周期与调仓周期不一致反而更好**。我最初把它当成 bug 去"修"，
实测证明原设定是对的。保留 10 日标签 / 20 日调仓。

### 第三轮：组合层挖到底了

本轮试的四项全部失败，但失败方式高度一致：

| 改动 | 结果 | 失败原因 |
|---|---|---|
| **行业上限**（每行业最多 1~2 只） | 年化 9.96%→8.66%（回撤 -24.0%→-22.3%） | 组合本来就不集中：最大行业仅占 20%，15 只分布在 12 个行业，没有多少集中度可削 |
| **配置集成**（前 3/5 名等权混合） | 年化 15.05%→13.24%/13.63%，波动 12.0%→11.1%/10.4% | 收益和风险的下降幅度基本相同，风险调整后无改善 |
| **连续仓位**（按偏离均线程度平滑调仓） | 年化 9.96%→6.95%，超额 3.38%→0.37% | 平均仓位被压到 50%，等于把 alpha 直接稀释一半 |
| **行业内相对强弱因子**（4 个） | 年化 9.96%→6.37%，7 年里 5 年变差 | 与 ret_20 等高度共线，只是把信号拆散到相关特征、放大打分尾部方差 |

**统一规律**：这四项的本质都是在稀释那个集中的高信念下注。唯一有效的是市场
状态闸门——因为它处理的是另一种失效模式（系统性崩盘），不触碰 alpha 的表达方式。

行业内因子的失败值得单独记一笔：**IC 从 0.0910 升到 0.0931，但组合反而变差**。
原因是组合只取打分分布的尾部（前 15 名 / 2800 只），而新增的低重要性共线因子
主要在扰动尾部排序，对整体 IC 的正面影响救不了尾部。**IC 提升不等于组合变好**。

### 嵌套 walk-forward 验证（本轮最重要的产出）

之前的参数都是在完整历史上挑的，分年度检验只能说明"不是靠某一年"。
这里做真正的样本外检验：**每个评估年份只用该年之前的数据在 42 个候选配置里选参数**，
再用选出的配置交易该年，最后把所有年份的样本外收益拼成曲线。

| 曲线 | 年化 | 累计 | 胜年 | 最差年 |
|---|---|---|---|---|
| **嵌套选择（真实可得）** | **15.05%** | +52.3% | 3/3 | +3.9% |
| 固定配置（全历史选参，偏乐观） | 17.66% | +62.9% | 2/3 | -2.3% |
| 事后最优（不可实现的上界） | 29.76% | +118.5% | 3/3 | +12.3% |
| 沪深300 | 5.68% | +18.0% | — | — |

三条结论：

1. **过拟合溢价约 2.6%/年**（15.05% vs 17.66%）。这是"不知道该用哪个参数"的真实代价，
   在可接受范围内。
2. **结构性选择是稳健的**：3 次嵌套选择全部选中 `inv_vol` 加权、全部选中带迟滞的闸门。
   不稳健的是具体数值——`top_n` 在 10/25 之间摇摆，均线周期在 MA20/MA60 之间摇摆。
3. **样本只有 3 个年份**（2024–2026，因为样本内需要至少 2 年历史），且这段时间
   包含 2024-09 后的普涨行情。**这个检验的说服力有限。**

复现：`python scripts/08_walkforward.py`，明细见 `output/walkforward.csv`。

## 架构

```
ashare/
  config.py       全部可调参数（成本、窗口、约束、闸门、权重方案）
  datasource.py   腾讯行情接口（多域名轮询）+ baostock 主列表 + 本地缓存
  universe.py     可交易股票池：ST/停牌/新股/低流动性/指数剔除、涨跌停判定
  factors.py      43 个量价因子（动量、波动、流动性、量价、技术、日内、市场关联）
  labels.py       未来超额收益标签（open-to-open，与回测执行口径严格对齐）
  model.py        LightGBM 滚动训练（walk-forward，标签必须在信号日前实现完毕）
  selection.py    选股约束、规模/波动中性化、三种市场状态闸门（含迟滞）
  portfolio.py    组合构建层：把打分转成目标持仓
  backtest.py     T+1 事件式回测：涨跌停/停牌约束、佣金/印花税/滑点、
                  100 股整手、三种权重方案、回撤刹车
  metrics.py      绩效指标：年化、夏普、回撤、IC、分层、换手
  signals.py      每日买卖信号、建议仓位与个股因子归因
web/app.py        FastAPI 接口
web/static/       深色终端风格看板（ECharts，本地内置无需外网）
```

数据流：`data/raw/*.csv`（逐股缓存）→ `data/cache/factors.pkl`（1.6GB 因子宽表）
→ `data/cache/preds.pkl`（滚动的全市场打分）→ `output/*`（回测与信号产物）。

构建按本次加载的实际数据决定是否复用。因子键包含日期、代码和整段有效行情，以及启用的行业/外部数据；评分键另含实际股票池、评分日期和训练设置。即使最后日期、文件大小和修改时间不变，中段有效量价修订也会使两级缓存失效。只改持仓数不必重训。旧版缓存下次正式构建会重算一次；不要为了本次修正覆盖需保留的研究快照。构建成功后信号另列行情日 `market_date` 与评分日 `score_date`。

## 关键设计决策

**十日超额收益用同一对开盘。** 信号在 t 日收盘后产生。股票和沪深300分别以 `open[t+11] / open[t+1] - 1` 计算十个交易区间的价格收益，股票减指数才是十日超额。任一端无有效开盘或无成交就留空，不以前收填补、不顺延到下一笔报价。收盘仍用于量价因子、市场开关和收盘净值，实际策略仍按原有调仓日交易。旧版构建曾用指数收盘扣减个股开盘收益；已冻结的旧预测、分层和回测表不因代码修正而自动刷新，也不能宣称策略收益因此提高。

**开盘成交与收盘估值分开。** t 日收盘的市场闸门、股票池、60 日波动率决定 t+1 开盘的目标；传给回测的逐日序列不需要提前平移。成交价格、涨跌停和停牌约束仍使用 t+1 开盘信息。t+1 收盘价可以改变收盘净值和实际持仓占比，但不能反过来改变当天开盘的订单。已提供的闸门若在信号日缺失，按关闭处理；信号日缺少股票池则不建新仓。

**防前视泄漏。** `tests/test_factors.py::test_factors_have_no_lookahead` 会截断未来数据
重算因子，要求历史值逐点不变；`model.py` 的训练集上界取 `t - horizon`，保证标签在
信号日之前已经实现完毕。

**横截面分位标准化。** 每天对每个因子做去极值 + 排序，消除量纲与风格轮动的影响。

**成本建模是真实的。** 佣金万 2.5（最低 5 元）、卖出印花税千 0.5、双边滑点千 1、
100 股整手、开盘涨停买不进、开盘跌停卖不出。年化 611% 的换手意味着成本约 2%–3%/年，
这也是裸信号从「理论正超额」变成「实际亏损」的原因之一。

## 能力边界

① **市场闸门是在同一段历史上选出来的参数**（MA20/MA60/MA120 里选了 MA60、再加迟滞带）。
   它没有独立的样本外验证，存在过拟合风险。换个市场环境可能立刻失效。
   缓解措施：分年度检验显示 6 个真实交易年超额全部为正（最差 +11.3%），
   且迟滞把历史翻转从 114 次降到 42 次，对参数扰动不那么敏感——但这**不等于**样本外有效。

② 前复权价格由接口按最新价回推，历史值会随分红送转变化，**缓存需定期刷新**
   （`python scripts/01_fetch.py --force`）。

③ ST 状态按当前证券名称**静态**剔除，无法还原历史某日真实的 ST 状态，这会带来
   存活偏差。

④ 涨跌停用前复权价近似判定，除权日附近可能误判。

⑤ 未建模：停牌复牌后的跳空、退市清算、融资融券成本、冲击成本、分红税。
   按 15 只、100 万资金估算，单票约 6.7 万，对日均成交额 3000 万以上的标的影响有限，
   但对名单里成交额偏低的个股（部分仅 4000 万），实际冲击成本会吞掉可观收益。

⑥ 因子全部来自量价数据，**不含财务基本面、行业分类、资金流向**。因此无法做行业
   中性化，组合可能在某一年严重集中在单一风格上。当前名单高度集中在创业板/科创板
   中小盘。

⑦ 滚动训练未严格隔离超参数选择集，绩效含轻微选择偏差。`top_n`、`weighting`、
   `regime_*` 都是在完整历史上比较后选定的，这部分偏差无法在样本内消除。

⑧ `top_n` 是风险偏好旋钮而非纯优化结果：10 只回测更好（年化 13.0%、夏普 0.71）
   但最大回撤 -26.9%、个股特质风险显著更高。默认 15 只是保守取值。

⑨ 分层收益顶部不单调：第 4 层（0.63%）高于第 5 层（0.55%），说明打分最顶端存在
   过度外推。已在界面如实展示，未做美化。

## 怎么读输出

- **建议仓位**：默认逆波动加权，不是等权。低波动股拿更多权重，因低波动股触顶被
  `max_weight`（10%）截断时剩下的权重会按比例分给其余标的，合计始终 100%。
- **榜内强度脊柱**：横向填充长度 = 该股在本次入选名单内的相对强弱（0–100%）。
  旁边数字是真实的横截面分位（1 位小数）。前 15 名的真实分位差距很小（99.6%–100%），
  所以脊柱改用榜内口径才能区分。
- **闸门横幅**：`闸门关闭` 时系统建议空仓，下面的候选名单仅作观察，**不应直接建仓**。
- **交易诊断**：`闸门离场` 反映策略空仓的时间比例，这是收益的主要来源之一。

## 每日收盘观察（本地、按需运行）

沿用最近一期模型分数，在当时有分数的股票中按排名取前 5%（向下取整），重新核验当日股票池，并筛选收盘高于滚动 20 日均线、5 日和 20 日涨幅都大于零的股票。价格缺口不前填；当天无有效行情则标为待核而非走弱。报告列出评分日期和交易日龄：不是每天都有新预测，达到原配置的 20 个交易日仍无新分数就停止筛选。市场开关与观察名单分开，关闸只观察，不开仓。默认同时展示此前人工关注的国电电力和重庆银行，不让手工关注标的自动入选。

```bash
python scripts/11_daily_watch.py                         # 只读预览，显示数据实际截止日
python scripts/11_daily_watch.py --date 2026-11-19       # 历史预览，不补记为当时发出的观察
python scripts/11_daily_watch.py --baseline               # 可选：空日志登记最近收盘为起点，标明非前瞻
python scripts/11_daily_watch.py --record                 # 上海当日收盘后且缓存有当天行情才登记
python scripts/11_daily_watch.py --review --json          # 复核全部登记事件；未到期或端点缺失单列
```

**交易日收盘后的手动用法：** `python scripts/01_fetch.py` 只更新数据。若要在更新成功后登记一次，运行 `python scripts/01_fetch.py --record`。取数按上海时间 15:00 和 BaoStock 交易日历确定最近应有的收盘，不把“最近七天有缓存”当作已更新；盘中、周末、节假日不登记。只有全批校验通过、必要指数均有目标日有效日线，并且目标正是上海当日收盘，才调用正式观察。正式登记前还核对目标日名册与观察程序读取的本地证券代码和名称；遇新增、退市或改名等差异会拒记，不默默替换旧名册，应先单独审阅。它不是完整的历次退市数据库。个股缺行不自动当停牌，行情或日历不确定时检查提示、稍后重试；不强行运行离线登记命令。`--limit` 仅排查子集，不能用来登记。增量更新不负责生成新评分，原评分过期仍会拒绝发布。

上面的 `11_daily_watch.py` 离线命令本身不联网、不训练、不交易，**不创建定时任务**。它用沪深300与中证500两份指数缓存交叉核对交易日；两者均缺同一日时，仅靠本地检查无法独立发现该缺口。跨时期复算仍受前复权修订、当前主名单与 ST 名称的局限。新进、持续、退出、行情待核均相对**上一次实际登记**，不把两次运行之间的缺报伪装成每日跟踪。文字版最多列 3 个重点，新进优先；完整清单、原评分日期和打分截面指纹保存在本地 SQLite 观察日志，`--json` 可查看。相同日相同内容不重复写入，冲突或倒序写入会被拒绝。

首次或重新入选按观察事件跟踪；人工跟踪项会注明来源。标签用信号日后的首个交易日开盘到再过 10 个交易日的开盘，分别给出股票涨跌、沪深300涨跌及两者之差；没有真实开盘则标缺失，不在其他日期补价。它们是观察结果，不是扣费策略收益；事后登记的基线与当日收盘后实际登记的事件分开。
